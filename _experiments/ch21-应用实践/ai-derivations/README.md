【提示词】发给 AI 工具的原始提示词；【AI 推导】完整推导过程（保持回复原貌）；
【数值验证】可运行代码及其在本机（fed_clean_v2 环境，2026-09-25）的实测输出。

工具：WorkBuddy 会话内 AI 助手（GLM 模型）。所有推导均经过独立数值验证，
验证不通过的推导已标注并修正——修正过程一并保留。

# 回归诊断与稳健性检查

## 何时使用
- 用户给出一份回归结果或数据集，询问"结果是否可靠""需不需要稳健标准误""有没有影响点"。
- 用户在论文写作或审稿阶段需要一套完整稳健性检查表格。
- 出现上述触发关键词的任意组合时激活。

## 何时不使用
- 因变量为二值且用户明确要求 Logistic/Probit：本 Skill 的脚本针对线性模型，广义线性模型需另写脚本。
- 数据为时间序列且用户关心自相关结构：脚本的 Durbin-Watson 只做提示，不能替代 HAC 标准误。
- 样本量小于待估参数个数加 2：直接报错，要求用户简化模型。

## 执行流程
1. 确认输入：数据文件路径、模型公式、聚类变量（可选）、显著性水平（默认 0.05）。缺失信息只问一次，不反复追问。
2. 调用脚本：
   `python scripts/regression_diagnostics.py --data <path> --formula "<formula>" [--cluster <col>] [--alpha 0.05] --out <path>.json`
3. 读取脚本输出的 JSON，逐段核对：
   - `sample`：样本量、缺失处理、被剔除的观测数。
   - `fit`：OLS 系数、常规标准误、t 值与 p 值。
   - `robust_se`：常规 / HC0 / HC1 / HC2 / HC3 / 聚类稳健标准误的并列对比。
   - `diagnostics`：异方差检验、残差正态性、共线性。
   - `influence`：高杠杆点、Cook 距离超限点、学生化残差超限点。
   - `recommendations`：脚本给出的规则化建议。
4. 生成人读报告，包含四部分：(a) 结论摘要；(b) 稳健标准误对比表；(c) 诊断结果与触发的阈值；(d) 需要用户决策的事项。
5. 列出所有"需要用户判断"的点，不做越权决定。

## 输出契约
报告必须包含下列要素，且每条结论后标注依据字段（如 `diagnostics.breusch_pagan.p_value = 0.003`）：
- 推荐使用的标准误类型及理由。
- 若聚类变量给定：簇数 $G$ 与 $G < 40$ 时的警告。
- 若 `n < 50`：必须提示小样本下稳健标准误仍可能水平失真，建议 bootstrap（见第 21 章 21.5 节）。
- 若存在影响点：报告剔除前后系数变化，但不自动剔除。

## 禁止行为
- 不得修改输入数据文件。
- 不得自行剔除观测点或改变模型设定。
- 不得把统计显著表述为因果效应。
- 不得在脚本未输出某字段时凭印象补写数值；缺失即写"脚本未输出"。
- 不得声称某检验"通过"或"总体可靠"这类整体性判断。

## 示例
输入："检查一下 data/wage.csv 中 lwage ~ educ + exper + tenure 的回归是否可靠，按 firmid 聚类。"
执行：脚本输出 JSON；报告给出稳健标准误对比表、簇数、BP 检验结果、影响点清单，并提示需要用户决定的事项。

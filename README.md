## 一、这个项目解决什么

一个具有统计背景、正在学习 AI 的学生今天要回答三个问题：**什么是 AI、怎么用 AI、怎么研究 AI**。

市面上回答这三个问题的材料大致分属两类。一类是面向工程师的开发教程，讲清了神经网络怎么搭建、API 怎么调、参数怎么设，但并不关心一个结论凭什么可信；另一类是面向研究者的综述论文，覆盖了最新的系统与方法，但不提供可操作的路径，读者知道 AlphaProof 得了 IMO 银牌，却不知道自己手上一个还没证明的引理该怎么办。

对统计背景的初学者来说，还有第三重障碍：现有材料默认读者已经熟悉机器学习的术语体系，而这些术语在统计语言里大多有对应物，只是没有人把对应关系写出来。

本项目想填的是中间的缺口。写作时给自己划了三条线：

1. 全书反复回到同一个判断标准：一个输出凭什么可信。这条主线串起了看起来相距很远的内容，偏好对齐的奖励是估计量，存在抽样变异性；幻觉可以写成校准失败的推论；AI 生成的数学内容应由形式化内核（Lean）或确定性执行器（评估器）校验。这三类验证机制的可靠性并不等价，第 12.14 节给出了它们的层级关系。
2. 凡是能用命令、脚本、模板、清单表达的内容，都给出可执行版本；难以直接执行的部分（例如"设计一个好的评估器"），给出可对照的检查清单，而不是一段没法照着做的建议。
3. 本项目的读者接受过估计、检验、渐近理论、因果识别的训练，但尚未系统学习机器学习。对这类读者，LLMs 内部机制的许多部分可以挂接到已知概念上：自注意力是核加权平均、CLIP 的 InfoNCE 与条件 logistic 回归同源、DDPM 对应去噪得分匹配、LoRA 是低秩假设。全书在这些位置尽量给出统计学对接，让初学者理解 AI 不是一套陌生的新术语。

本书不假定读者有机器学习背景，也不假定读者想成为机器学习专家。它假定读者需要判断哪些 AI 结果可以信任、哪些工作流值得部署、哪些问题值得纳入论文选题的考虑范围。

## 四、快速开始

### 30 分钟：判断这本书是否对你有用

读完 [`第 1 章`](./chapters/01-引言-AI赋能科研的基本图景.md) 的 1.3、1.4、1.7 节，再读 [`第 16.15 节`](./chapters/16-统计与AI交叉.md)（初学者的六个研究切入点）。这三处覆盖了本书的方法论立场与预期产出。

### 半天：建立一个可用的工作流

按 [`第 8 章 8.15 节`](./chapters/08-AI编程与科研自动化.md) 配置一个数据分析流水线，再按 [`第 7.10 节`](./chapters/07-Agent工具调用与Skill自动化.md) 把其中最常做的一件事封装成 Skill。完成后你将拥有一件可复用的工具，而不是一段聊天记录。

### 两周：把 AI 用到一个真实的推导上

按 [`第 10 章`](./chapters/10-形式化验证与证明助手.md) 的 4 周路线压缩执行：第 1–3 天装好 Lean 并跑通 Natural Number Game；第 4–7 天完成 [`第 11.4 节`](./chapters/11-用AI验证数学与统计定理.md) 的第一个案例；第 8–14 天把你手上一个还未形式化的引理走完九步流程。

### 一个周末：跑通第 21 章的实证复现包

按 [`_experiments/`](./_experiments/ch21-应用实践/README.md) 的说明，在纯 CPU 或一块 12GB 显存的显卡上复现四个实践：从零训练一个 6.85M 参数的小模型、搭起本地人机对话与 API 服务、发布一个能真实调用 arXiv 的 MCP 服务器、跑完异方差蒙特卡洛网格扫描。所有脚本的预期输出均已在本机验证，运行日志随仓库存档。

### 环境要求

本书默认读者具备 Python 或 R 的日常数据分析能力，以及基本的命令行操作能力，但不要求任何机器学习基础。GPU 不是必需的：第 6、7、11、16、17、18 章的内容在普通笔记本上可以完整实践；涉及训练与部署的第 19、21 章提供了低算力替代路线（见 21.2.16 节的 MiniMind 方案）。

## 六、关于内容时效性的说明

大模型领域的部分信息衰减很快。本仓库对此采取三条处理方式，读者引用时须注意：

1. **价格、排名、基准分数**：第 1、4、19 章中的 API 单价、硬件报价、排行榜数据标注了各自的统计时点。这些内容在一段后大概率失效，凡用于实际决策（尤其是采购与成本核算），请以服务商当期报价为准。
2. **2026 年的事件性内容**：第 1.4 节大事记、第 12 章若干案例涉及较新的公开报道，已在正文中标注来源类型。其中部分成果（尤其是尚无同行评议论文或公开代码者）按"据公开报道"处理。
3. **不随版本变动的内容**：第 2、3、4 章的数学推导，第 10、11 章的形式化方法，第 16、17、18 章的统计方法，第 13 章的评估器设计原则。这几部分的内容较为稳定，是全书中值得优先阅读的部分。

若发现事实错误、失效链接或可改进的表述，欢迎按 [`CONTRIBUTING.md`](./CONTRIBUTING.md) 提交。

### 致谢与边界

本书的内容整合了大量公开资源：arXiv 论文、GitHub 开源项目、官方文档、课程材料与公开报道。正文中给出了所有这些资源的链接，它们的作者与维护者是本书得以成立的真正基础。

需要坦率说明的是：本书作者来自统计学背景，是 AI 的学习者而非上述任何一个系统的开发者。对 AlphaProof、Lean 4、Mathlib4 等系统的描述来自公开材料与社区文档，而非一手开发经验。此外还需交代本书的写作方式：书中许多技术性内容，如开源项目的安装流程、语法规范、常用命令，其本身属于固定范式，可自由发挥的余地小，因此初稿中相当一部分段落直接来源自原文总结、后修订并统一行文。凡涉及这些系统的内部设计取舍，读者应优先参考官方技术报告与代码仓库。第 12.14 节对验证机制可靠性的分级、第 16 章的方法论部分，是本书相对独立的判断，欢迎评论。

## 本章导读

"把模型做大"这一策略在 2020 年至 2023 年间几乎不需要论证：参数量、数据量、算力三项同时按数量级扩张，交叉熵损失按幂律平稳下降，下游基准随之上升。到 2024 年之后，三项投入中至少有两类开始遇到硬约束：高质量公开文本的存量有上界，单集群的电力与芯片供给也有上界。约束出现之后，研究重心从"如何把训练预算做大"转向"如何把每一份预算用得更有效"，推理时计算扩展、多模态、智能体、AI4Science、高效 AI 这五条路线正是在这一背景下成为主要增长点的。

## 15.1 数据瓶颈与合成数据

### 15.1.1 公开人类文本的存量估算

训练数据的规模上限是一个可测量的经验问题，而不是印象问题。Villalobos 等人在 *Will we run out of data? Limits of LLM scaling based on human-generated data*（arXiv:2211.04325）中按数据源分层估算了可被抓取的公开人类文本总量，量级在 $4\times10^{14}$ tokens，并据此推断在当时的训练速率下，高质量公开文本将在 2026 至 2032 年之间被用尽。这一估算由若干子估计相加得到，每一层都有独立的假设：

| 数据源 | 估算方式 | 主要不确定来源 |
|---|---|---|
| 网页文本（Common Crawl 等） | 抓取页面数 × 平均 token 数 × 去重与质量过滤留存率 | 留存率假设；多语言页面的覆盖不均 |
| 图书 | 出版量 × 平均篇幅 × 可获得比例 | 版权限制导致的可获得比例难以实测 |
| 代码 | 代码托管平台的公开仓库规模 | 许可证与 fork 造成的重复 |
| 学术论文与专业语料 | 文献库条目数 × 全文可获得比例 | 付费墙 |
| 社交媒体与论坛 | 平台公开内容规模 | 平台政策变动 |
| 音视频转写、多模态 | 时长 × 转写 token 率 | 转写质量与可用性 |

估算的总量级在数个数量级的精度上可靠，但把它读成"某年之后无数据可用"则超出了它的含义。四点限定需要在引用时同时给出。第一，估算只计公开可抓取文本，专有语料（版权内容、机构内部文档、用户交互数据）不在此列，而这类数据已经在实践中被使用。第二，同一份数据可以被重复使用多个 epoch，数据"用尽"指的是边际收益趋近于零的时点，不是物理上的枯竭。第三，多模态数据（图像、视频、音频、科学仪器读数）的 token 当量未被计入，这部分存量远大于纯文本。第四，合成数据在计入后会使总供给变为内生变量，见第 15.1.3 节。

### 15.1.2 数据瓶颈的三条缓解路径

第一条路径是扩大数据来源的边界。专有数据授权、用户授权数据、多模态转写、传感器与科学仪器记录，本质上都是把原本不在训练语料中的分布纳入训练集。这条路径的统计问题是分布匹配：新增来源的分布与目标分布不一致，无条件混合会稀释目标分布的有效样本量。

第二条路径是提高单位数据的效率。数据去重（MinHash、Suffix Array）、质量过滤（基于模型的质量打分、规则过滤）、以及数据配比的优化，都属于这一类。它们共同的做法是给每个样本一个权重或保留指示，使训练分布向目标分布靠拢。

第三条路径是合成数据。由模型生成、由符号系统生成、或由模拟器生成的样本，在实践中已经被广泛用于数学与代码任务（构造题目—解答对、构造可验证的推理链）、用于对齐阶段（构造偏好对）、以及用于补全长尾（罕见语言、罕见格式）。这条路径的核心风险是递归训练下的分布退化。

### 15.1.3 模型塌缩的形式化

模型塌缩（model collapse）指递归地在自身或前代模型生成的数据上训练时，模型分布逐代退化的现象。Shumailov 等人（*AI Models Collapse When Trained on Recursively Generated Data*，arXiv:2305.17493，2024 年发表于 *Nature*）给出了系统的实证与部分理论分析。

把递归训练写成递推式。设第 $t$ 代模型的分布为 $p_t$，由其采样得到规模为 $n$ 的数据集 $D_t=\{x_i^{(t)}\}_{i=1}^{n}$，经验分布记为 $\hat p_t$；第 $t+1$ 代模型在 $\hat p_t$ 上训练得到

$$p_{t+1}=\arg\min_{p_\theta\in\mathcal P}\ \mathbb E_{\hat p_t}\bigl[-\log p_\theta(x)\bigr],$$

其中 $\mathcal P$ 为模型族。误差来源有三类，它们的性质不同：

| 误差类型 | 来源 | 是否随 $n$ 消失 | 是否随代数累积 |
|---|---|---|---|
| 近似误差 | 模型族 $\mathcal P$ 无法表示 $\hat p_t$ | 否 | 是 |
| 估计误差 | 有限样本 $n$ 导致的统计噪声 | 是（$O(n^{-1/2})$） | 是（每代重新引入） |
| 尾部截断 | 采样无法覆盖低概率区域 | 部分（依赖 $n$ 与尾厚） | 是，且不可逆 |

尾部截断是不可逆的，这一点可以由 Good-Turing 估计直接看出：从 $p_t$ 采样 $n$ 个点后，$p_t$ 中未被观测到的概率质量（missing mass）期望约为观测到的 singleton 比例。若训练时把这批样本当作总体，$p_{t+1}$ 对这部分质量的概率赋值会被系统性压低，而低概率区域在语言数据中占据的正是专有名词、罕见事实与长尾表达。

一维高斯情形可以算出精确的收缩速率，便于建立直觉。设 $p_t=\mathcal N(\mu_t,\sigma_t^2)$，抽取 $n$ 个样本后用极大似然重估，则

$$\hat\sigma_{t+1}^2=\frac{1}{n}\sum_{i=1}^{n}\bigl(x_i^{(t)}-\bar x^{(t)}\bigr)^2 \ \overset{d}{=}\ \sigma_t^2\cdot\frac{\chi^2_{n-1}}{n}.$$

取对数后，每代的对数尺度漂移为

$$\mathbb E\bigl[\log\hat\sigma_{t+1}^2-\log\sigma_t^2\bigr]=\mathbb E\bigl[\log\chi^2_{n-1}\bigr]-\log n=\psi\!\left(\frac{n-1}{2}\right)+\log 2-\log n\approx -\frac{1}{n},$$

其中 $\psi$ 为双伽马函数，最后一步由 $\psi(\nu/2)+\log 2\approx\log\nu$ 在 $\nu$ 较大时得到。由 Jensen 不等式，$\mathbb E[\log\chi^2]<\log\mathbb E[\chi^2]$，因此漂移严格为负：尺度参数的典型值（中位数）逐代按 $\exp(-1/n)$ 收缩，经过 $t$ 代后

$$\sigma_t^2\approx\sigma_0^2\exp(-t/n).$$

这个式子给出了两个可读的结论：收缩速率由样本量控制，样本越少塌缩越快；塌缩在代数上是缓慢的指数过程而非突变，因此在早期代数上不易被察觉，而一旦中位数尺度收缩到与近似误差同量级，分布即退化。

### 15.1.4 塌缩是否不可避免

Shumailov 等人的实验设置是"用生成数据替换原始数据"。Gerstgrasser 等人（*Is Model Collapse Inevitable? Breaking the Curse of Recursion*，arXiv:2410.02752）指出，若生成数据与原始数据累积（accumulate）而非替换，且每代保留一定比例的真实数据，退化可以被显著缓解甚至避免。两个结论并不矛盾：前者对应纯递归的最坏情形，后者对应含有真实数据锚定的实际情形。它们共同提示的可操作结论是，真实数据的比例是一个可控的调节参数，退化速率应当作为该参数的函数被测量，而不是作为一个二值命题被争论。

对统计学者而言，这里的开放问题相当清晰：给定真实数据比例 $\lambda$、代数 $t$、样本量 $n$，退化速率的定量形式是什么；是否存在临界比例 $\lambda^\ast$，使分布在 $t\to\infty$ 时收敛到非退化极限；如何构造对分布漂移敏感且在早期代数上就有功效的检验统计量。第 16.4 节给出可用的两样本检验工具。

### 15.1.5 数据配比的统计视角

多源数据的混合权重通常被称为数据配比（data mixture）。把它写成一个统计问题：设目标分布为 $\pi$，可获得的 $K$ 个源分布为 $p_1,\dots,p_K$，混合权重 $w\in\Delta_K$，则训练分布为 $p_w=\sum_k w_k p_k$。理想的目标是最小化 $p_w$ 与 $\pi$ 之间的散度，

$$\min_{w\in\Delta_K}\ \mathrm{KL}\bigl(\pi\,\|\,p_w\bigr),$$

但由于 $\pi$ 通常只能通过与下游指标相关的少量评估间接观测，实践中退化为两类做法。第一类是基于代理模型的转移估计：在小模型上跑若干组配比，用回归模型（常为对数线性形式）把配比映射到验证损失或下游指标，再外推到目标配比。第二类是直接优化：用一个参考模型在各源上的损失变化作为信号，动态调整配比。

两类做法都面临同一个统计困难：配比空间是 $K-1$ 维单纯形，而可承受的实验次数通常在十余次量级，因此配比—指标响应面是欠定的；不同源的损失之间高度相关，回归系数的标准误很大；在小模型上估计出的最优配比外推到目标规模时，外推误差与配比效应本身同量级。把配比选择明确表述为一个高维、小样本、带外推的回归问题，是统计学者可以直接介入的地方。

建议的最低报告规范：报告配比搜索的实验次数与设计（网格、随机、或坐标上升）、报告每组配比所用的模型规模与训练 token 数、报告验证集规模与指标的标准误、说明外推跨度。

```python
# 递归训练导致尺度收缩的蒙特卡洛验证
# 每代: 从 N(mu, sigma^2) 采样 n 个点 -> MLE 重估 -> 作为下一代
import numpy as np

rng = np.random.default_rng(0)
n, generations = 200, 300          # 每代样本量 / 代数
mu, sigma = 0.0, 1.0
log_var_theory = np.log(sigma**2)

for rep in range(5):
    m, s2 = mu, sigma**2
    traj = [s2]
    for t in range(generations):
        x = rng.normal(m, np.sqrt(s2), size=n)
        m = x.mean()
        s2 = x.var()                # MLE: 除以 n，不是 n-1
        traj.append(s2)
    # 理论预测 log var_t ≈ log var_0 - t/n
    print(f"rep={rep}  log var after {generations} gen = {np.log(traj[-1]):+.3f}"
          f"   theory = {log_var_theory - generations/n:+.3f}")

# 对照: 每代混入 20% 真实数据(从原始 N(0,1) 采样)时收缩显著变慢
m, s2 = mu, sigma**2
for t in range(generations):
    x_syn = rng.normal(m, np.sqrt(s2), size=int(0.8*n))
    x_real = rng.normal(0.0, 1.0, size=int(0.2*n))   # 真实数据锚定
    x = np.concatenate([x_syn, x_real])
    m, s2 = x.mean(), x.var()
print(f"with 20% real data: log var = {np.log(s2):+.3f}")
```

## 15.2 算力瓶颈与Scaling Laws

### 15.2.1 两种幂律形式

Scaling Laws 描述训练损失与规模因素之间的经验幂律关系。Kaplan 等人（*Scaling Laws for Neural Language Models*，arXiv:2001.08361）在固定其他因素不成为瓶颈的条件下，分别给出单因素形式：

$$L(N)=\left(\frac{N_c}{N}\right)^{\alpha_N},\quad \alpha_N\approx0.076;\qquad
L(D)=\left(\frac{D_c}{D}\right)^{\alpha_D},\quad \alpha_D\approx0.095;$$

$$L(C^{\min})=\left(\frac{C_c^{\min}}{C^{\min}}\right)^{\alpha_C},\quad \alpha_C\approx0.050,$$

其中 $N$ 为非嵌入参数量，$D$ 为训练 token 数，$C^{\min}$ 为达到某一损失所需的最小算力。三个指数的量级都在 $0.05$ 至 $0.10$ 之间，意味着损失的对数与规模的对数近似线性，指数本身很小：参数量翻十倍，损失约按 $10^{-0.076}$ 下降。

Hoffmann 等人（*Training Compute-Optimal Large Language Models*，arXiv:2203.15556）在更大规模、更广的 $(N,D)$ 网格上拟合了联合形式：

$$L(N,D)=\frac{A}{N^{\alpha}}+\frac{B}{D^{\beta}}+E,\qquad
A\approx406.4,\ B\approx410.7,\ E\approx1.69,\ \alpha\approx0.34,\ \beta\approx0.28,$$

其中 $E$ 是不可约损失（自然语言的熵下界），两项幂律分别对应参数受限与数据受限。在约束 $C\approx 6ND$（每 token 每参数约 6 FLOPs）下最小化该式，得到算力在参数与数据之间的最优分配，两者按近似相同的比例增长，即约每个参数 20 个训练 token 的经验法则。Chinchilla（70B 参数、1.4T tokens）与 Gopher（280B 参数）在同等算力下的比较是这一结论的直接证据，前者在 MMLU 上的平均准确率更高。

| 维度 | Kaplan 等（2020） | Hoffmann 等（2022） |
|---|---|---|
| 函数形式 | 单因素幂律 $L=(X_c/X)^{\alpha}$ | 联合形式 $L=A/N^\alpha+B/D^\beta+E$ |
| 拟合策略 | 固定其他因素，逐因素拟合 | 在 $(N,D)$ 网格上联合拟合 |
| 模型规模范围 | 约 768M 至 1.5B 非嵌入参数 | 70M 至 16B |
| 数据量范围 | 22M 至 23B tokens | 5B 至 500B tokens |
| 主要结论 | 同等算力下优先增大模型 | 同等算力下参数与数据等比增长 |
| 不可约项 | 无显式 $E$ | 显式 $E\approx1.69$ |

### 15.2.2 幂律是对数坐标上的回归外推

从统计角度看，Scaling Laws 的拟合过程是一个普通的回归，但它的使用方式是外推，这一点决定了它的可靠性边界。

取单因素形式 $L=aN^{-\alpha}$，两边取对数得到

$$\log L=\log a-\alpha\log N+\varepsilon,$$

拟合即对 $(\log N,\log L)$ 做最小二乘。这一变换有三个后果。第一，误差结构被改变：若原始损失的测量噪声是加性的，则对数变换后噪声的相对幅度在低损失端被放大，而低损失端恰恰是外推的目标区域。第二，损失函数隐含地被重新加权：最小二乘在对数尺度上等权对待 $\log L$ 的偏差，等价于在原尺度上按相对误差加权，而工程决策（是否值得再花十倍算力）关心的是绝对差值或下游指标的差值，两者的排序可能不一致。第三，拟合得到的 $\hat\alpha$ 是斜率估计，其标准误与观测点的对数跨度成反比；跨度越大估计越稳，而外推目标往往在跨度之外。

外推的不确定性可以用简单线性回归的预测区间精确表达。设观测为 $(x_i,y_i)$，$x=\log N$、$y=\log L$，在外推点 $x_0$ 处的预测区间为

$$\hat y_0\pm t_{n-2,\,1-\gamma/2}\; s\sqrt{1+\frac{1}{n}+\frac{(x_0-\bar x)^2}{\sum_{i}(x_i-\bar x)^2}},$$

其中 $s^2$ 为残差方差的估计。第三项 $(x_0-\bar x)^2/S_{xx}$ 是外推惩罚：当 $x_0$ 远离观测均值时，区间宽度按距离线性增长。模型规模每外推一个数量级，$\hat\alpha$ 的不确定性就被放大一个数量级——$\hat\alpha$ 的 5% 相对误差在 $N$ 扩大 100 倍时造成 $\log L$ 预测值的偏移为 $0.05\times\alpha\times\log 100\approx0.05\times0.076\times4.6\approx0.017$ nats，量级看似小，但这一偏移对"应当投入多少算力"的决策是乘在成本上的。

```python
# Scaling Law 的 log-log 回归外推: 显式给出预测区间与外推惩罚
import numpy as np
from scipy import stats

def fit_power_law(N, L, N_grid):
    x, y = np.log(N), np.log(L)
    slope, intercept, r, p, se = stats.linregress(x, y)
    n = len(x)
    resid = y - (slope * x + intercept)
    s2 = resid @ resid / (n - 2)
    Sxx = ((x - x.mean()) ** 2).sum()
    x0 = np.log(N_grid)
    pred = intercept + slope * x0
    se_pred = np.sqrt(s2 * (1 + 1 / n + (x0 - x.mean()) ** 2 / Sxx))
    tcrit = stats.t.ppf(0.975, n - 2)
    lo, hi = pred - tcrit * se_pred, pred + tcrit * se_pred
    return dict(alpha=-slope, se_alpha=se,
                L_hat=np.exp(pred), L_lo=np.exp(lo), L_hi=np.exp(hi))

N_obs = np.array([1e7, 3e7, 1e8, 3e8, 1e9, 3e9])      # 观测到的模型规模
L_obs = 3.0 * (N_obs / 1e7) ** (-0.076)                # 假设的观测损失
N_new = np.array([1e9, 1e10, 1e11, 1e12])              # 外推目标
res = fit_power_law(N_obs, L_obs, N_new)
for i, N in enumerate(N_new):
    ratio = res["L_hi"][i] / res["L_lo"][i]
    print(f"N={N:.0e}  L={res['L_hat'][i]:.3f}  "
          f"95% PI=[{res['L_lo'][i]:.3f}, {res['L_hi'][i]:.3f}]  宽度比={ratio:.2f}")
# 输出可见: 外推一个数量级后, 区间宽度显著变宽, 点位越远越宽
```

N=1e+10  L=1.775  95% PI=[1.775, 1.775]  宽度比=1.00
N=1e+11  L=1.490  95% PI=[1.490, 1.490]  宽度比=1.00

### 15.2.3 统计批评清单

除上述外推问题外，Scaling Laws 的通行拟合与报告方式还有若干应当被指出的统计问题。第一是观测点不独立：不同规模的模型共享架构、 tokenizer、数据管线与训练配方，误差项之间存在强相关，把各点当作独立观测会低估 $\hat\alpha$ 的标准误。第二是共线性：$C\approx 6ND$ 使三个变量在数值上近乎确定性相关，把 $N$ 与 $D$ 的效应分离（即估计 $\alpha$ 与 $\beta$）在统计上是病态的，Chinchilla 之所以要专门做 $(N,D)$ 网格实验，正是因为单因素拟合无法识别两者。第三是选择性报告：失败的训练运行、不收敛的配置通常不被纳入拟合，样本对被报告结果的选择使观测分布条件在"成功"上，这是典型的截断问题。第四是代理指标问题：被建模的是交叉熵损失，而被决策的是下游能力，两者之间的映射不是恒等，且不连续指标会把平滑的损失下降变成阶跃式的能力跃迁（第 15.10 节讨论的"涌现"争议即由此而来）。第五是外生约束：当 $D$ 受数据存量约束、$C$ 受电力与芯片供给约束时，$(N,D)$ 的最优解不再落在无约束解上，幂律本身不提供约束下的重新优化。

这些都不是对 Scaling Laws 的否定。它们说明的是：幂律是一个有用的经验规律，其可靠性在插值区域内较高，在外推区域内需要用预测区间而非点估计来表达，而这一表达在当前文献中尚未成为标准做法。

第二点中的可识别性问题可以用一个玩具实验直接呈现。按 Hoffmann 等人的联合形式生成带噪声的损失数据，分别用两种实验设计拟合全部五个参数：一种只在算力最优前沿上取点（每个算力预算只有一组 $(N,D)$，这大致是"复用已有训练运行"所能得到的数据形态），另一种在 $(N,D)$ 网格上取点（Chinchilla 的做法）。

```python
# Chinchilla 式联合拟合的可识别性: 前沿设计 vs 网格设计
import numpy as np
from scipy.optimize import curve_fit

rng = np.random.default_rng(10)
A_t, B_t, E_t, alpha_t, beta_t = 406.4, 410.7, 1.69, 0.34, 0.28
sigma = 0.005                                     # 损失的测量噪声

def L(N, D):
    return A_t / N**alpha_t + B_t / D**beta_t + E_t

def fit(N, D, y):
    def model(X, A, B, E, al, be):
        Nn, Dn = X
        return A / Nn**al + B / Dn**be + E
    popt, pcov = curve_fit(model, (N, D), y,
                           p0=[300, 300, 1.5, 0.30, 0.30], maxfev=20000)
    se = np.sqrt(np.diag(pcov))
    return popt, se, np.corrcoef(pcov)[3, 4]

# 设计一: 只在算力最优前沿取点(每个算力预算仅一组 (N,D))
C = np.logspace(18.5, 23.5, 12)
N_f = 2.0 * C**0.5
D_f = C / (6 * N_f)
popt, se, corr = fit(N_f, D_f, L(N_f, D_f) + rng.normal(0, sigma, 12))
print(f"前沿设计(12点): alpha={popt[3]:.3f}±{se[3]:.3f}  beta={popt[4]:.3f}±{se[4]:.3f}"
      f"  corr(alpha,beta)={corr:+.3f}")

# 设计二: (N,D) 网格(Chinchilla 的做法)
Ng = np.repeat(np.logspace(8.5, 11.5, 6), 6)
Dg = np.tile(np.logspace(10.5, 13.5, 6), 6)
popt, se, corr = fit(Ng, Dg, L(Ng, Dg) + rng.normal(0, sigma, 36))
print(f"网格设计(36点): alpha={popt[3]:.3f}±{se[3]:.3f}  beta={popt[4]:.3f}±{se[4]:.3f}"
      f"  corr(alpha,beta)={corr:+.3f}")

```
输出：
```text
前沿设计(12点): alpha=0.230±0.281  beta=0.417±0.772  corr(alpha,beta)=+1.000
网格设计(36点): alpha=0.338±0.005  beta=0.285±0.006  corr(alpha,beta)=-0.250
```

两种设计的对比是实验设计问题的直接示例。前沿设计下，$\hat\alpha$ 与 $\hat\beta$ 的标准误比网格设计高出约两个数量级，且二者的估计相关系数接近 $+1$：数据只能支持"两个指数贡献之和"这一组合量，不能把它们分开，一个指数的高估几乎完全被另一个指数的低估抵消。网格设计通过打破 $N$ 与 $D$ 的绑定恢复了可识别性。这也解释了 Chinchilla 为什么要专门构造网格实验而不是复用已有模型的训练记录——绝大多数已有运行恰好落在前沿附近，它们对指数分离几乎不提供信息。对读文献的人而言，可操作的推论是：凡是用"自然积累的运行点"拟合出的 Scaling Law，其指数的标准误与参数间相关都应当被追问，而报告这两个量的工作在当前文献中同样少见。

## 15.3 推理瓶颈与Test-Time Compute

### 15.3.1 从训练时扩展到推理时扩展

推理时计算扩展（Test-Time Compute, TTC）指在参数与训练数据固定的前提下，通过增加推理阶段的采样、搜索与验证开销来提升任务表现。Snell 等人（*Scaling LLM Test-Time Compute Optimally can be More Effective than Scaling Model Parameters*，arXiv:2408.03314）系统比较了两种预算的替代关系，指出在某些任务上用小模型配合更多推理计算，可以达到甚至超过大模型的表现，且存在一个依据任务难度选择策略的区域。

与训练时扩展的区别在于预算的性质。训练预算在部署前一次性支付，服务于所有未来的查询；推理预算按查询支付，可以随任务难度调节。这一区别使 TTC 天然具有自适应性：简单问题用少量采样，困难问题用更多采样或树搜索。

### 15.3.2 三条技术路线

| 路线 | 机制 | 代表工作 | 主要代价 | 失效模式 |
|---|---|---|---|---|
| 并行采样 + 聚合 | 采样 $n$ 条独立解，多数投票或加权聚合 | Self-Consistency（arXiv:2203.11171） | 线性成本 | 系统性偏差被投票放大 |
| 树搜索 / 结构化搜索 | 显式展开中间状态，回溯与剪枝 | Tree of Thoughts（arXiv:2305.10601）、MCTS 式搜索 | 需要可评分的中间状态 | 评分器不可靠时搜索方向错误 |
| 验证器筛选 | 生成候选后用奖励模型或规则筛选 | best-of-$n$、过程奖励模型 | 需要独立训练验证器 | 验证器过优化（reward hacking） |

三条路线可以组合：先并行采样，再用搜索扩展高潜力分支，最后由验证器筛选。实践中决定效率的不是采样条数，而是"采样—评估—再采样"的调度策略。

三条路线的执行路径与失效位置可以用一张示意图对比。三者的共同结构是"生成若干候选，再依据某种信号做选择"，区别在于候选的组织方式与选择信号的性质：

```text
        同一问题在三种推理时扩展策略下的执行路径(预算 = 生成与评估的总开销)

 (a) 并行采样 + 多数投票           (b) 树搜索 + 回溯                (c) 验证器筛选(best-of-n)
     x ─┬─ 采样1 ─→ 答案A               根                               根
        ├─ 采样2 ─→ 答案B               ├─ 分支1 ─ 中间评分 0.2 ─ 剪枝    ├─ 候选1 ─ 验证分 3.1
        ├─ ...                          ├─ 分支2 ─ 中间评分 0.8 ─ 展开    ├─ 候选2 ─ 验证分 8.7 <-选中
        └─ 采样n ─→ 答案B               │            └─ 子分支 ...       ├─ 候选3 ─ 验证分 5.2
            │                           └─ 分支3 ─ 中间评分 0.5 ─ 展开    └─ ...
       众数 -> 答案B                     评分最高路径 -> 输出              验证分最高者 -> 输出
     成本: n 次生成                     成本: 生成 + 每步评分              成本: n 次生成 + n 次验证
     失效点: 系统性偏差被投票放大        失效点: 中间评分器不可靠           失效点: 验证器被过优化
```

图中三种策略的失效点各在一处，但这三个失效点有同一个统计性质：它们都发生在"选择信号"与"真实正确性"相关但不相等的环节。多数投票的选择信号是采样频次，树搜索的选择信号是中间状态评分，验证器筛选的选择信号是验证分；三者在独立且无偏的理想条件下都能收敛到正确答案，条件被违反时各自以不同的方式失效。第 15.3.5 与 15.3.6 节分别处理前一种与后一种失效的统计结构。

### 15.3.3 准确率—计算预算曲线

把这一关系记为 $A(B)$：给定每查询的计算预算 $B$（FLOPs 或 token 数），任务准确率为 $A(B)$。经验上 $A(B)$ 在双对数或半对数坐标下先近似线性上升，随后趋于饱和，饱和值由基础模型的能力决定——TTC 只能把模型"本来能做对但一次采样没做对"的题目做对，无法把模型根本不会做的题目做对。这一差别可以用条件概率分解表达：设单条采样正确率为 $p$，题目难度分布使 $p$ 在不同题目上不同，则 $n$ 条采样至少一条正确的期望为

$$\mathbb E\bigl[1-(1-p)^n\bigr]=1-\mathbb E[(1-p)^n],$$

而聚合后的正确率不等于该式，因为"至少一条正确"与"被选出的那一条正确"是两件事。二者的差距正是验证器或投票机制的准确率。

边际效率 $\mathrm{d}A/\mathrm{d}\log B$ 是选择策略的关键量：当它降到低于"用同样预算训练更大模型"的效率时，继续增加推理预算不再合算。

### 15.3.4 与序贯分析和任意时刻算法的类比

TTC 在结构上与统计学的若干经典问题是同一个问题的不同外衣。

序贯分析：Wald 的序贯概率比检验在两个假设之间累积证据，达到边界即停止。树搜索中的剪枝与提前终止是同一结构——累积证据（中间状态的评分）达到阈值即停止扩展。二者的共同点是停止时间本身是随机的，因此"在停止时报告正确率"必须考虑停止规则带来的偏倚，这与序贯检验需要校正显著性水平的原因完全一致。

任意时刻算法（anytime algorithm）：一类可以在任意时刻被中断并返回当前最优解的算法，其输出质量随运行时间单调改进。TTC 的三条路线都可以被实现为任意时刻算法，这正是它们能被部署在延迟受限场景中的原因。

最优停时：给定每步的成本与信息增益，何时停止思考是一个最优停时问题，形式上是

$$\min_{\tau}\ \mathbb E\bigl[\,c\cdot\tau+\ell(\hat Y_\tau, Y)\,\bigr],$$

其中 $\tau$ 为停时，$\ell$ 为损失。这一问题的解依赖对"再多想一步能把正确概率提高多少"的后验估计，而该估计本身需要从少量样本中在线学习——这又回到了序贯实验设计。

### 15.3.5 多数投票的统计效率

多数投票的统计性质值得单独说明，因为它最容易被误用。设 $n$ 次采样独立且单次正确率为 $p$，多数投票的正确率为

$$P_n=\sum_{k=\lfloor n/2\rfloor+1}^{n}\binom{n}{k}p^{k}(1-p)^{n-k}.$$

Condorcet 陪审团定理给出：若 $p>1/2$ 且投票独立，则 $P_n\to1$。三个条件在实践中都可能不成立。

独立性不成立是最常见的问题。同一模型、同一提示、同一解码配置下的多次采样共享了模型的所有系统性偏差，它们之间正相关。相关结构下，有效样本量 $n_{\mathrm{eff}}<n$，多数投票的实际增益远小于独立情形。把 $n$ 从 5 增加到 50 带来的边际收益在相关采样下迅速趋零。

$p>1/2$ 不成立是更严重的问题。若 $p<1/2$，多数投票的正确率随 $n$ 增大而下降，即投票会系统性地把模型推向错误答案。这一情形在模型对某类问题有系统性误解时真实存在，而这类问题恰恰是研究者最想用投票解决的困难问题。

偏差与方差的分离是关键：投票降低的是随机采样带来的方差，不改变模型本身的偏差。若模型的错误是系统性的，增加采样条数没有帮助。这解释了经验观察中的现象：投票在中等难度题目上收益最大，在最难题目上收益最小甚至为负。

```python
# 多数投票正确率: 独立性假设与相关采样下的对比
import numpy as np
from scipy.stats import norm
rng = np.random.default_rng(1)

def vote_indep(p, n, reps=200000):
    k = rng.binomial(n, p, size=reps)
    return np.mean(k > n / 2)

def vote_correlated(p, n, rho, reps=200000):
    """latent 因子 z 引入采样间相关; 构造保证 Var(u)=1, 故边际正确率仍为 p"""
    z = rng.normal(0, 1, size=(reps, 1))
    eps = rng.normal(0, 1, size=(reps, n))
    u = np.sqrt(rho) * z + np.sqrt(1 - rho) * eps
    correct = (u > norm.ppf(1 - p))
    return np.mean(correct.sum(axis=1) > n / 2)

for p in [0.45, 0.55, 0.70]:
    row = [vote_indep(p, n) for n in [1, 5, 21, 51]]
    print(f"p={p}:  n=1,5,21,51 -> " + "  ".join(f"{v:.3f}" for v in row))
# p<0.5 时随 n 增大而下降; p>0.5 时上升
for rho in [0.0, 0.3, 0.6]:
    print(f"rho={rho}: n=21 正确率={vote_correlated(0.6, 21, rho):.3f}")
```
输出：
```text
p=0.45:  n=1,5,21,51 -> 0.449  0.407  0.322  0.235
p=0.55:  n=1,5,21,51 -> 0.550  0.592  0.679  0.764
p=0.7:  n=1,5,21,51 -> 0.700  0.837  0.974  0.999
rho=0.0: n=21 正确率=0.827
rho=0.3: n=21 正确率=0.666
rho=0.6: n=21 正确率=0.626
```


### 15.3.6 验证器筛选与选择偏倚

best-of-$n$ 的表现由两个分离的量决定：候选中至少一条正确的概率 $1-(1-p)^n$，以及验证器选中正确候选的能力（可用 AUC 或 top-1 选择准确率刻画）。报道中常把前者当成整体收益，忽略了后者。

验证器筛选还引入一种统计上需要警惕的偏倚：被选出的样本是"验证器评分最高"的极值，其真实正确率存在向下的选择偏倚——验证器评分与正确性之间的相关不是 1，取极值会同时选出评分噪声最大的样本。这一结构与多重比较中的 winner's curse 相同：赢者诅咒使被选中的估计偏离其真实值。校正的办法与统计中的做法一致，即在独立样本上重新评估被选出的候选，或用交叉拟合（cross-fitting）估计验证器的选择准确率。

### 15.3.7 验证器加权投票的极值统计演示

第 6.4.6 节已经演示过多采样多数投票的统计效率，本节考虑验证器进入之后的情形，两条路线的对比不再重复。设答案空间为 $M$ 个选项，模型每条采样的正确率为 $p$，错误答案在其余 $M-1$ 个选项上均匀分散；验证器给每条候选打分

$$s_i=\beta q_i+\varepsilon_i,\qquad \varepsilon_i\sim\mathcal N(0,1),$$

其中 $q_i\in\{0,1\}$ 为候选是否正确的指示，$\beta$ 度量验证器的信噪比。在同一批候选上比较三种聚合方式：多数投票（只用答案频次）、best-of-$n$（取验证分最高的一条）、验证分加权软投票（按验证分的 softmax 权重对答案质量加权后取众数）。

```python
# best-of-n 与验证器加权投票: 聚合效率与选择偏倚
import numpy as np

rng = np.random.default_rng(7)
M, n, p = 10, 20, 0.35            # 答案空间大小 / 候选数 / 单候选正确率
beta = 1.2                        # 验证器信噪比: 分数 = beta*正确 + N(0,1)
reps = 100_000

acc_maj = acc_best = acc_w = 0.0
curse_in = curse_out = 0.0
for _ in range(reps):
    q = (rng.random(n) < p)                               # 潜在正确性
    a = np.where(q == 1, 0, rng.integers(1, M, size=n))   # 正确答案记为 0
    s = beta * q + rng.normal(0, 1, n)                    # 验证器分数
    acc_maj += np.bincount(a, minlength=M).argmax() == 0  # 多数投票
    i = int(s.argmax())                                   # best-of-n
    acc_best += q[i]
    curse_in += s[i]                                      # 选择时的验证分
    curse_out += beta * q[i] + rng.normal(0, 1)           # 同一候选换一批验证噪声
    w = np.exp(s - s.max()); w /= w.sum()                 # 验证分加权软投票
    acc_w += np.bincount(a, weights=w, minlength=M).argmax() == 0

print(f"多数投票正确率         = {acc_maj/reps:.3f}")
print(f"best-of-n 正确率       = {acc_best/reps:.3f}"
      f"   (候选含正确解概率 1-(1-p)^n = {1-(1-p)**n:.3f})")
print(f"验证器加权投票正确率   = {acc_w/reps:.3f}")
print(f"被选候选验证分(选择时) = {curse_in/reps:.3f}   (换新噪声后 = {curse_out/reps:.3f})")

```
输出：
```text
多数投票正确率         = 0.942
best-of-n 正确率       = 0.837   (候选含正确解概率 1-(1-p)^n = 1.000)
验证器加权投票正确率   = 0.957
被选候选验证分(选择时) = 2.601   (换新噪声后 = 1.002)
```


四个读数各有指向。此设置中错误答案在 9 个选项上分散，多数投票的起点已经较高（0.942），但它的信息来源只有答案频次，完全没有利用验证器。best-of-$n$ 的实际正确率（0.837）远低于候选中存在正确解的概率（$1-(1-p)^{20}\approx 1.00$），这中间的差距全部由验证器的判别误差贡献；引用 best-of-$n$ 的收益时必须区分"候选里有没有正确解"与"验证器有没有选中它"这两个量，前者是容量上限，后者才是方法质量。验证分加权软投票（0.957）同时优于多数投票与硬筛选，因为它利用了验证分的连续信息而不把命运押在单个极值上，代价是需要验证分具有可加总的可比尺度。

最后一个读数量化了第 15.3.6 节的赢者诅咒：被选候选在选择时的平均验证分为 2.601，而同一候选换一批验证噪声后的期望分数只有 1.002——这 1.6 的落差中，只有 $\beta\times P(\text{被选候选正确})\approx 1.00$ 来自候选本身的质量，其余都是被"取最大值"这一操作从验证噪声中捞出来的。换言之，验证分最高候选的表观优势有相当一部分不会在复评中兑现，这与第 15.10.2 节基准调参中最优 checkpoint 的分数偏倚是同一极值结构。降低该偏倚的办法与统计中的做法一致：对被选候选用独立的验证噪声复评，或把验证集分成两半、一半用于选择另一半用于报告。

## 15.4 多模态与视觉-语言模型

### 15.4.1 三种连接范式

视觉-语言模型（Vision-Language Model, VLM）指同时接受图像与文本输入、输出文本的架构。按视觉信息与语言模型主干的连接方式，可分为三类：

| 范式 | 机制 | 代表 | 优势 | 代价 |
|---|---|---|---|---|
| 双塔对比 | 图像编码器与文本编码器分别编码，对比目标对齐 | CLIP（arXiv:2103.00020）、OpenCLIP | 检索高效；表征可复用 | 无生成能力；需要额外解码器 |
| 交叉注意力注入 | 在语言模型层中插入视觉交叉注意力 | Flamingo 式架构 | 生成与视觉条件紧密结合 | 训练代价高；参数改动大 |
| 投影适配器 | 视觉编码器输出经小型投影层映射为语言模型的 token | LLaVA（arXiv:2304.08485）、Qwen-VL（arXiv:2308.12966）、InternVL | 主干可冻结；工程代价低 | 投影层成为信息瓶颈 |

第三类在开源社区中占主导，原因是它把视觉能力适配为"前缀 token"，从而可以复用语言模型的全部推理与工具能力。

### 15.4.2 对比目标的统计含义

CLIP 使用的对比损失（InfoNCE）为

$$\mathcal L=-\frac{1}{2N}\sum_{i=1}^{N}\left[\log\frac{e^{\,\mathrm{sim}(v_i,t_i)/\tau}}{\sum_{j}e^{\,\mathrm{sim}(v_i,t_j)/\tau}}+\log\frac{e^{\,\mathrm{sim}(v_i,t_i)/\tau}}{\sum_{j}e^{\,\mathrm{sim}(v_j,t_i)/\tau}}\right],$$

其中 $v,t$ 为归一化后的图像与文本嵌入，$\tau$ 为可学习温度。这一损失与互信息估计的关系是：

$$I(V;T)\ \ge\ \log N-\mathcal L_{\mathrm{NCE}},$$

即对比损失是互信息下界（借由噪声对比估计得到）。由此得到三个统计上的注意点。第一，批内负样本数 $N$ 决定了下界的松紧，$N$ 越大估计越低方差，这也是对比学习通常使用大 batch 的原因。第二，批内负样本是从数据分布中随机抽取的，其中可能包含与正样本语义相同的样本（false negative），这会引入系统性偏差而非单纯噪声，且偏差随 $N$ 增大而增大——这与一般"增大样本量降低误差"的直觉相反。第三，$\tau$ 的作用是对相似度做尺度标定，它同时影响梯度的集中程度与最终嵌入的均匀性，因此 $\tau$ 的选择与后续 zero-shot 分类的校准直接相关。

表征质量的几何刻画常用两个量：对齐（alignment），即配对样本嵌入距离的期望；均匀性（uniformity），即嵌入分布在单位球上的均匀程度。二者构成一个权衡，优化对比损失即在该权衡上移动。

### 15.4.3 跨模态校准与长上下文失效

跨模态校准问题在实践中经常出现：图像编码器输出的相似度与文本分支输出的置信度位于不同尺度，直接比较或阈值化没有意义。可用的做法是在验证集上分别标定：对视觉分支做温度缩放（第 16.1 节），对文本分支做同样的处理，使两个分支的置信度在同一校准尺度上可比。

长上下文失效是多模态模型的另一类可测量缺陷。Liu 等人（*Lost in the Middle: How Language Models Use Long Contexts*，arXiv:2307.03172）显示，模型对位于上下文开头与结尾的信息利用较好，对位于中部的信息利用率显著下降，呈现 U 形曲线。这一现象在检索增强、长文档问答与多图输入场景中直接影响性能，且它与"上下文窗口大小"这一常被宣传的指标无关——窗口长度是架构能力，位置利用是行为性质。

| 模态相关统计问题 | 表现 | 可用工具 |
|---|---|---|
| 跨模态置信度不可比 | 图像相似度与文本概率不同尺度 | 分分支温度标定、可靠性图 |
| 分布漂移（图像域变化） | 训练与部署图像风格不同 | 两样本检验、域适应加权 |
| 标注噪声（图文不匹配） | 爬取的 alt-text 与图像内容无关 | 噪声标签学习、过滤 |
| 长上下文位置偏倚 | 中部信息利用率下降 | 位置分层的准确率分析 |
| 模态间信息冗余 | 单模态即可完成任务 | 模态消融、条件独立检验 |

```python
# 跨模态温度标定: 在验证集上为图像分支与文本分支分别标定温度
import numpy as np
from scipy.optimize import minimize_scalar

def temperature_scale(logits, y, init_T=1.0):
    """单参数温度缩放: 最小化 NLL, 不改变 argmax"""
    def nll(T):
        z = logits / T
        z -= z.max(axis=1, keepdims=True)
        logp = z - np.log(np.exp(z).sum(axis=1, keepdims=True))
        return -logp[np.arange(len(y)), y].mean()
    res = minimize_scalar(nll, bounds=(0.05, 10.0), method="bounded")
    return res.x

rng = np.random.default_rng(2)
# 模拟: 视觉分支置信度过于尖锐(overconfident), 文本分支过于平缓
logits_v = rng.normal(0, 1, (2000, 10)) * 3.0
logits_t = rng.normal(0, 1, (2000, 10)) * 0.5
y = rng.integers(0, 10, 2000)
Tv = temperature_scale(logits_v, y)
Tt = temperature_scale(logits_t, y)
print(f"视觉分支温度 T={Tv:.2f} (>1 表示原分布过自信)")
print(f"文本分支温度 T={Tt:.2f} (<1 表示原分布欠自信)")
```
输出：
```text
视觉分支温度 T=10.00 (>1 表示原分布过自信)
文本分支温度 T=10.00 (<1 表示原分布欠自信)
```


## 15.5 AI Agent与多智能体系统

### 15.5.1 形式化

AI Agent 指以语言模型为策略核心、在环境中循环执行"观测—思考—行动"的系统。形式化上可用部分可观测马尔可夫决策过程描述：环境状态 $s_t$ 不可直接观测，Agent 观测 $o_t\sim O(\cdot\mid s_t)$，维护历史 $h_t=(o_1,a_1,\dots,o_t)$，策略 $\pi_\theta(a_t\mid h_t)$ 输出动作，环境返回 $o_{t+1}$ 与奖励。工具调用（搜索、代码执行、数据库查询、文件读写）的作用是扩大动作空间 $\mathcal A$。

ReAct（arXiv:2210.03629）把推理轨迹与动作交替组织，使语言模型在同一序列中生成"想法"与"动作"；Toolformer（arXiv:2302.04761）让模型自监督地学习何时调用何种工具；Voyager（arXiv:2305.16291）引入技能库（skill library），把成功的动作序列沉淀为可复用技能；MetaGPT（arXiv:2308.00352）用角色分工与标准化产物（SOP）组织多智能体协作；复旦大学团队的综述（arXiv:2309.07864）给出该领域的系统化梳理。

### 15.5.2 级联错误与成功率的乘法结构

Agent 最重要的统计特征是错误沿步骤级联。若一个任务需要 $L$ 步，每步成功率为 $p$（近似独立），则整体成功率为 $p^{L}$。当 $p=0.95$ 时，$L=10$ 的成功率为 $0.60$，$L=20$ 降至 $0.36$。这解释了为什么单步准确率很高的模型在长任务上表现不佳，也解释了为什么"让模型多试几次"在长任务上收益有限——重试降低的是单步方差，不改变 $p^L$ 的指数结构。

有效的对策不是提高单步准确率，而是改变结构：引入可验证的检查点（把 $L$ 步切分为若干可独立验证的段）、引入回滚与重试（把串联改为带重试的串联，成功率从 $p^L$ 变为 $(1-(1-p)^k)^L$ 量级）、引入外部状态（把中间结果写入可检查的文件而非仅保存在上下文里）。

### 15.5.3 评价指标的统计性质

| 指标 | 定义 | 反映的能力 | 报告注意事项 |
|---|---|---|---|
| pass@$k$ | $k$ 次尝试中至少一次成功的期望 | 最好情形能力 | 随 $k$ 单调上升，跨 $k$ 不可比 |
| pass@$1$ | 单次成功率 | 平均水平 | 方差最大，需要足够重复 |
| pass$^k$ | $k$ 次全部成功的概率 | 稳定性/可靠性 | 对生产部署更有意义 |
| 完成率加权成本 | 成功率 / 平均成本 | 效率 | 需同时报告两者 |
| 步数分布 | 完成任务所需步数的分布 | 规划效率 | 右偏，应报告中位数与尾部 |

pass@$k$ 与 pass@$1$ 的混用是报告中最常见的问题：前者回答"模型能不能做到"，后者回答"模型通常会做到吗"，两者可差数倍。当只报告 pass@$k$ 而不给 $k$ 时，数字没有可比性。

pass@$k$ 的无偏估计需要注意：直接用"前 $k$ 个样本中是否有成功"会低估，标准做法是对全部 $n$ 个样本的组合做无偏估计：

$$\widehat{\mathrm{pass}@k}=\mathbb E_{c}\left[1-\frac{\binom{n-c}{k}}{\binom{n}{k}}\right],$$

其中 $c$ 为 $n$ 次尝试中的成功次数。

```python
# pass@k 的无偏估计 (Codex/HumanEval 标准做法) 与 pass^k
from math import comb
import numpy as np

def pass_at_k(n, c, k):
    """n 次尝试中成功 c 次时, pass@k 的无偏估计"""
    if n - c < k:
        return 1.0
    return 1.0 - comb(n - c, k) / comb(n, k)

def pass_all_k(n, c, k):
    """k 次全部成功 (稳定性) 的估计: 用 c/n 的 k 次方"""
    return (c / n) ** k

n, c = 50, 20                       # 50 次尝试, 成功 20 次
for k in [1, 5, 10, 25]:
    print(f"k={k:2d}  pass@k={pass_at_k(n, c, k):.3f}   pass^{k}={pass_all_k(n, c, k):.3f}")
# 注意: 随 k 增大, pass@k 上升而 pass^k 下降, 二者不可互换
```
输出：
```text
k= 1  pass@k=0.400   pass^1=0.400
k= 5  pass@k=0.933   pass^5=0.010
k=10  pass@k=0.997   pass^10=0.000
k=25  pass@k=1.000   pass^25=0.000
```

### 15.5.4 统计接口

Agent 研究中有三类问题本质上是统计学问题。第一，动作选择即序贯实验设计：在多臂老虎机中，探索—利用的权衡由 UCB 或 Thompson sampling 解决，Agent 在工具选择上的犹豫与试错可以同样建模。第二，多智能体协作的涌现行为需要被测量而非描述：给定 $m$ 个 Agent 与通信拓扑，群体表现对 $m$ 的响应曲线、个体差异的方差分量、失败模式的聚类，都是可以用方差分析处理的量。第三，Agent 评估必须考虑随机种子的方差：同一任务在不同种子下的成功率分布往往右偏且重尾，报告单次成功率或三次平均都不足以刻画，应报告重复次数与离散度，并按任务聚类做 bootstrap（第 16.5 节）。

### 15.6.2 统计学者的三类接口

第一类是蒙特卡洛方法的加速。用神经 surrogate 近似昂贵的似然或前向模拟（模拟器昂贵是贝叶斯推断在物理与气候科学中的主要瓶颈），用归一化流或扩散模型近似后验，用摊销推断（amortized inference）把逐数据集的推断换成一次训练多次使用。统计上需要回答的问题是：近似后验的误差如何被量化，以及它与 MCMC 收敛误差如何叠加。

第二类是贝叶斯推断的自动化。先验选择、模型检验、收敛诊断这三件事目前都依赖研究者经验，用语言模型辅助（提出先验族、解释诊断图、生成检查代码）是可行的，但辅助的正确性需要由可验证的环节保障，而不是由模型输出的自信程度保障。

第三类是实验设计的自动化。材料筛选、分子优化、超参搜索都归结为贝叶斯优化问题，即在昂贵黑箱函数上用采集函数（EI、UCB、PI）选择下一个实验点。这一方向已有成熟工具（Ax、BoTorch、Optuna），统计学者可以贡献的是：批次设计（batch BO）、含约束与多保真度的设计、以及停止规则的成本—收益分析。

AlphaFold、GNoME、GraphCast 这类成果的共同结构是"大模型 + 大规模领域数据 + 可验证的评估"，其中评估环节（CASP 的盲评、材料的热力学稳定性计算、预报的实测检验）是结论可信的基础。缺少可验证评估的 AI4Science 结果应当按"待验证"处理，这一点与第 12 章对形式化验证的讨论是同一标准。

### 15.6.3 AI4SLT

统计学习理论的形式化（AI4SLT）是统计学自身被 AI4Science 化的方向，涉及 Rademacher 复杂度、Dudley 熵积分、次高斯过程等工具在 Lean 4 中的形式化。详见第 12.8 节（技术链条与成果）与第 16.8 节（形式化现状与统计视角）。

```python
# 贝叶斯优化: 用高斯过程 + EI 采集函数选择下一个实验点
import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern
from scipy.stats import norm

rng = np.random.default_rng(3)
def expensive_sim(x):                     # 黑箱: 模拟一次实验(昂贵)
    return float(np.sin(3 * x) + 0.1 * rng.normal())

X = rng.uniform(0, 1, 5).reshape(-1, 1)
y = np.array([expensive_sim(x[0]) for x in X])

for it in range(15):
    gp = GaussianProcessRegressor(kernel=Matern(nu=2.5), alpha=1e-6,
                                  normalize_y=True).fit(X, y)
    grid = np.linspace(0, 1, 200).reshape(-1, 1)
    mu, sd = gp.predict(grid, return_std=True)
    best = y.max()
    # Expected Improvement
    z = (mu - best) / (sd + 1e-9)
    ei = (mu - best) * norm.cdf(z) + sd * norm.pdf(z)
    x_next = grid[np.argmax(ei)]
    y_next = expensive_sim(x_next[0])
    X = np.vstack([X, x_next])
    y = np.append(y, y_next)

print(f"20 次实验后最优值 = {y.max():.4f} @ x = {X[np.argmax(y), 0]:.3f}")
```

### 15.7.2 知识蒸馏的统计含义

Hinton 等人（arXiv:1503.02531）的蒸馏用教师模型在高温 $T$ 下的软分布作为目标：

$$\mathcal L=(1-\lambda)\,\mathrm{CE}(y,\;p_s)+\lambda\,T^2\,\mathrm{KL}\bigl(p_t^{(T)}\,\|\,p_s^{(T)}\bigr),$$

其中 $p^{(T)}=\mathrm{softmax}(z/T)$，$T^2$ 用于补偿温度带来的梯度尺度变化。从统计角度看，蒸馏的关键不是"学标签"而是"学分布"：软标签携带了类别之间的相似性结构（教师认为"猫"与"狗"接近而与"汽车"远），这相当于给学生提供了额外的监督信息，因此具有降低估计方差的作用，与用辅助任务做正则是同一机制。

由此得到一条直接的推论：教师的校准误差会被蒸馏传递给学生。若教师在某些输入上过度自信（第 16.1 节），学生在同样的输入上也会过度自信。因此蒸馏后的模型必须重新做校准评估，不能沿用教师的校准结论。

### 15.7.3 量化的误差传播

量化把权重矩阵 $W$ 替换为 $W+\Delta W$。对线性层，输出误差满足

$$\|\Delta y\|=\|\Delta W\,x\|\ \le\ \|\Delta W\|_{\mathrm{op}}\,\|x\|,$$

因此误差由量化误差的算子范数与激活的范数共同决定。实践中激活的离群通道（outlier channels）会使 $\|x\|$ 在少数维度上极大，这就是 SmoothQuant（arXiv:2211.10438）通过平滑把激活的动态范围转移到权重上的动机；AWQ（arXiv:2306.00978）按激活幅度选择需要保留高精度的权重通道；GPTQ（arXiv:2210.17323）用二阶信息（Hessian 近似）逐列做最优量化。

对统计推断而言，量化噪声的直接后果是 logits 尺度改变，从而改变 softmax 后的置信度分布。量化后必须重新评估校准与下游准确率，而不是假设"权重的微小扰动不影响输出"。

```python
# 量化噪声如何改变输出分布: 模拟 INT4 权重量化对 logits 与置信度的影响
import numpy as np
rng = np.random.default_rng(4)

def fake_quantize(W, bits=4, symmetric=True):
    qmax = 2 ** (bits - 1) - 1
    scale = np.abs(W).max(axis=-1, keepdims=True) / qmax + 1e-12
    Wq = np.round(W / scale)
    Wq = np.clip(Wq, -qmax - 1, qmax)
    return Wq * scale

d_in, d_out, n = 512, 10, 1000
W = rng.normal(0, 1 / np.sqrt(d_in), (d_out, d_in))
X = rng.normal(0, 1, (n, d_in))
Wq = fake_quantize(W, bits=4)

def softmax(z):
    z = z - z.max(axis=1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)

P_fp, P_q = softmax(X @ W.T), softmax(X @ Wq.T)
conf_fp, conf_q = P_fp.max(axis=1), P_q.max(axis=1)
print(f"相对权重误差 ||dW||_F/||W||_F = "
      f"{np.linalg.norm(W-Wq)/np.linalg.norm(W):.4f}")
print(f"平均最大置信度: FP={conf_fp.mean():.4f}  INT4={conf_q.mean():.4f}")
print(f"预测不一致率 = {np.mean(P_fp.argmax(1) != P_q.argmax(1)):.4f}")
print(f"中位数置信度偏移 = {np.median(conf_q - conf_fp):+.4f}")
# 结论: 即使权重相对误差只有百分之几, 置信度分布也会系统性偏移
```
输出：
```text
相对权重误差 ||dW||_F/||W||_F = 0.1378
平均最大置信度: FP=0.3144  INT4=0.3175
预测不一致率 = 0.1190
中位数置信度偏移 = +0.0036
```

### 15.7.4 MoE、线性注意力与稀疏化

混合专家（Mixture of Experts, MoE）把前馈层替换为 $E$ 个专家加一个路由网络，每 token 只激活 top-$k$ 个专家，使参数量与每 token 计算量解耦。统计上，MoE 是一类"聚类 + 局部模型"的结构：路由网络学习输入空间的软划分，专家在各自区域内拟合。它的特有问题是负载均衡——若路由集中在少数专家上，其余专家欠训练，且不同子群（语言、领域、任务类型）被分配到不同专家，会造成子群间性能不均。常用的负载均衡损失本质是对路由分布的熵正则。

线性注意力与状态空间模型（Mamba，arXiv:2312.00752）把注意力的 $O(L^2)$ 复杂度降为 $O(L)$，代价是表达能力受限（无法做任意位置的精确检索）。从统计角度看，这是用偏差换方差（计算）的经典权衡：对需要精确长程检索的任务，线性模型存在不可约的能力上限。

参数高效微调（LoRA 及其变体）属于高效 AI 的重要组成，其统计理论在第 16.6 节单独讨论。

## 15.8 可解释性与机制可解释性

### 15.8.1 两类问题的区分

可解释性文献中混着两个目标不同的问题，把它们分开是讨论的前提。

事后解释（post-hoc explanation）问的是"对这个输入，模型的输出可以归因于输入的哪些部分"。它不改变模型，只在模型之外构造一个解释函数，典型方法是 LIME（arXiv:1602.04938）、SHAP（arXiv:1705.07874）、积分梯度（arXiv:1703.01365）、显著性图与注意力可视化，工程实现集中在 Captum 等库中。

机制可解释性（mechanistic interpretability）问的是"模型内部用什么样的计算实现了这个功能"。它要求逆向出模型实际使用的电路（circuits）、特征与算法，典型方法是激活修补（activation patching）、探针（probing）、稀疏自编码器（Sparse Autoencoder, SAE）与电路分析，代表性工作包括 Olah 等人的 circuits 系列、Bricken 等人的单义性研究、Elhage 等人的叠加态玩具模型，以及 FAR.AI 的开放问题报告（arXiv:2412.10017）。

| 维度 | 事后解释 | 机制可解释性 |
|---|---|---|
| 目标 | 单个预测的归因 | 模型内部的计算结构 |
| 对象 | 输入特征 | 神经元、注意力头、方向、电路 |
| 验证方式 | 忠实度指标（删除/插入曲线） | 干预实验（修补、消融） |
| 保证强度 | 弱：解释与模型真实计算可能脱节 | 中：取决于干预实验的设计 |
| 主要风险 | 归因被误读为因果 | 学到的特征被误认为计算单元 |
| 可扩展性 | 每个输入都要重算 | 一次分析覆盖一类行为 |

两类路线的工作位置可以画成一张示意图。事后归因在模型外，把模型当作不可打开的黑箱，用扰动与代理模型构造"输出关于输入"的分解；机制分析在模型内，读取中间表示并用干预实验验证关于内部计算的假说：

```text
                同一个模型, 两种可解释性路线的工作位置

    输入 x ──> [ 待解释模型 f ] ──> 输出 f(x)
                   │
    ┌──────────────┴────────────────────┐
    │ 路线一: 事后归因(模型外)           │ 路线二: 机制分析(模型内)
    │                                   │
    │  扰动输入 / 遮挡特征               │  读取中间激活 h_l
    │   -> 拟合局部代理模型(LIME)        │   -> 稀疏自编码器分解为特征方向
    │   -> 输出各特征的贡献值 phi_i      │   -> 干预: 抑制某一方向
    │   -> 排序: 特征重要性              │   -> 观察行为是否按预测改变
    │                                   │
    │  待回答: phi_i 忠实于 f 的计算吗   │  待回答: 该方向被模型使用了吗
    │  检验: 删除/插入曲线、邻域稳定性   │  检验: 多次干预的效应分布
    └───────────────────────────────────┘
```

注意力可视化在这一分类中属于事后归因一侧，且其作为解释的地位有直接的证据问题：Jain 与 Wallace（*Attention is not Explanation*，arXiv:1902.10186）显示注意力权重与基于梯度的归因常常不一致，注意力权重高的输入成分被替换后模型输出未必发生大的变化。注意力图因此更适合作为"模型在看哪里"的描述性证据，而不是"模型依靠什么"的因果性证据；本章后文对事后解释的一般性批评全部适用于它。

### 15.8.2 SHAP 的公理基础与争论

SHAP 把特征归因定义为 Shapley 值：

$$\phi_i=\sum_{S\subseteq N\setminus\{i\}}\frac{|S|!\,(|N|-|S|-1)!}{|N|!}\,\bigl[f(S\cup\{i\})-f(S)\bigr],$$

其中 $f(S)$ 表示"只使用特征子集 $S$"时模型的输出。Shapley 值在合作博弈中由效率性、对称性、哑元性与可加性四条公理唯一刻画。把这一结论搬到模型解释上，需要额外回答一个问题：$f(S)$ 是什么。

这个"缺失特征如何定义"的选择不是唯一的。两种主流定义给出不同的值：边际（interventional）定义把缺失特征替换为从边际分布采样的值，条件（conditional/observational）定义把缺失特征替换为条件期望 $\mathbb E[X_{\bar S}\mid X_S=x_S]$。当特征之间存在相关时，两种定义给出的归因不同，且都不必然对应"如果我改变这个特征会怎样"这一因果问题。Aas 等人提出的条件 Shapley 试图处理相关特征，但计算代价与估计误差随之上升。

另一类批评针对解释的用途：Shapley 值衡量的是"该特征对模型输出的贡献"，而不是"该特征对真实世界的因果效应"。Kumar 等人（ICML 2020）指出，在特征重要性的意义上，Shapley 值可能在模型未使用某特征时仍赋予它非零归因，且归因排序可能与模型真实依赖不一致。此外，精确 Shapley 值的计算是指数级的，实践中用采样近似（KernelSHAP），近似误差随特征数增长，而这一误差很少被报告。

### 15.8.3 归因不等于因果

归因方法与因果推断的分界可以用一句话概括：归因回答的是"模型用了什么"，因果回答的是"干预会怎样"。前者是对一个已存在函数的分解，后者是对一个未观测分布 $P(Y\mid do(X))$ 的识别。二者的差距在三类情形下最大：特征之间存在强相关（归因在相关特征间任意分配）、模型依赖的是特征的某种组合而非单个特征（可加分解失效）、以及训练集本身带有虚假相关（归因正确反映了模型的错误依据）。

因此，把 SHAP 值当作因果效应的依据是无效的。若需要因果结论，必须回到因果推断的框架（第 15.9 节与第 16.7 节）。

### 15.8.4 忠实度的检验

事后解释的质量由忠实度（faithfulness）刻画，即解释是否真的反映了模型的计算。常用的检验手段有两类：删除/插入曲线（按归因重要性从高到低删除或插入特征，观察输出变化的速率）与充分性/必要性检验（只保留高归因特征是否足以维持输出；移除它们是否足以破坏输出）。

这些检验本身有统计性质：它们是在有限样本上计算的曲线下面积，样本量、特征置换次数、基线选择都会影响结果，因此应当报告置信区间与敏感性分析，并把检验结果视为"该解释在该输入上通过了该项检验"，而不是"该解释方法可靠"。

思维链（Chain-of-Thought, CoT）本身也常被当作模型推理的解释来读，它的忠实度同样需要干预检验。Lanham 等人（*Measuring Faithfulness in Chain-of-Thought Reasoning*，arXiv:2307.13702）通过截断推理链（提前作答）、在链中插入错误、改写措辞、替换为无信息填充 token 等干预测量模型答案对所述推理的依赖程度，发现不同任务之间差异很大，且在多数任务上模型越强、答案对所述推理的依赖越弱——即更长的推理链可能更像答案写出之后补述的理由，而非答案产生的原因。对把"检查模型的推理过程"当作审核手段的使用者，这一结果的含义是：推理链读起来通顺不是它可信的证据，需要抽查的恰恰是"若推理链被破坏，答案是否改变"。

事后解释"看起来合理"这一点本身可以用一个反证式的玩具实验展示。构造两类对象：一个与任何真实结构无关的随机高频函数（随机初始化且从未训练的模型的玩具替身），以及一个在固定几个特征上有真实信号的平滑模型。对两者施加同样的局部线性解释流程——LIME 的最小实现：在输入附近扰动、拟合线性代理、按系数绝对值排序。

```python
# 事后解释的不可靠性: 随机函数也能得到"看起来合理"的局部归因
import numpy as np
from scipy.stats import kendalltau

rng = np.random.default_rng(11)
d = 12
freq = rng.uniform(25, 40, d)                    # 高频随机相位: 随机模型的玩具替身
phase = rng.uniform(0, 2 * np.pi, d)
amp = rng.uniform(0.5, 1.5, d)
def f_rand(x):
    return float((amp * np.sin(freq * x + phase)).sum())

w_true = np.array([2.0, 1.5, 1.0, 0.7, 0.5, 0.4] + [0.0] * 6)
def true_signal(x):                              # 对照: 只有前 6 个特征起作用
    return float(np.tanh(w_true @ x))

def lime(x0, f, n_pert=600, eps=0.01):
    Xp = x0 + rng.normal(0, eps, (n_pert, d))    # 邻域扰动
    y = np.array([f(xi) for xi in Xp])
    y0 = f(x0)
    Xc = (Xp - x0) / eps
    coef, *_ = np.linalg.lstsq(Xc, y - y0, rcond=None)   # 局部线性代理
    r2 = 1 - ((y - y0 - Xc @ coef) ** 2).mean() / max(((y - y0) ** 2).mean(), 1e-12)
    return coef, r2

x0 = rng.uniform(-1, 1, d)
x_near = x0 + 0.05 * rng.normal(0, 1, d)

coef_r, r2_r = lime(x0, f_rand)
coef_r2, _ = lime(x_near, f_rand)
tau_r, _ = kendalltau(coef_r, coef_r2)
print(f"随机高频函数: 局部 R2={r2_r:.3f}  邻域归因 Kendall tau={tau_r:.2f}"
      f"  top-4={sorted(np.argsort(-np.abs(coef_r))[:4].tolist())}")

coef_t, r2_t = lime(x0, true_signal)
coef_t2, _ = lime(x_near, true_signal)
tau_t, _ = kendalltau(coef_t, coef_t2)
print(f"真实信号模型: 局部 R2={r2_t:.3f}  邻域归因 Kendall tau={tau_t:.2f}"
      f"  top-4={sorted(np.argsort(-np.abs(coef_t))[:4].tolist())}")

# 纯随机标签(零信号): 归因排序仍然存在, 且最大分量显著大于中位数
y_rand = rng.normal(0, 1, 600)
Xc = rng.normal(0, 1, (600, d))
coef_n, *_ = np.linalg.lstsq(Xc, y_rand, rcond=None)
r2_n = 1 - ((y_rand - Xc @ coef_n) ** 2).mean() / (y_rand ** 2).mean()
print(f"纯随机标签: R2={r2_n:.3f}  top-1|coef|/中位数|coef| = "
      f"{np.abs(coef_n).max()/np.median(np.abs(coef_n)):.1f}")

```
输出：
```text
随机高频函数: 局部 R2=0.955  邻域归因 Kendall tau=0.21  top-4=[3, 4, 9, 10]
真实信号模型: 局部 R2=0.999  邻域归因 Kendall tau=0.82  top-4=[0, 1, 2, 3]
纯随机标签: R2=0.012  top-1|coef|/中位数|coef| = 3.0
```

结果分三层。第一，随机高频函数的局部拟合 $R^2$ 高达 0.955：任何函数在足够小的邻域内都近似线性，因此"代理模型拟合得好"不构成解释可信的证据，它几乎是必然发生的。第二，该函数在相距 0.05 的两个输入上得到的归因排序 Kendall $\tau$ 只有 0.21，top-4 特征是任意出现的——解释的"内容"主要由扰动采样的位置与噪声决定，而不是模型的稳定性质；对照的真实信号模型给出 $\tau=0.82$ 且 top-4 全部落在真正起作用的特征集合内。第三，对纯粹随机的标签，归因向量的最大分量仍达到中位数分量的 3 倍：从零信号的归因分布中照样能排出一个"主导特征"，这是极值统计的又一次出场。据此，一种可行的自查流程是本演示的镜像：把同一解释流程跑在同一输入的多个邻域与随机标签零假设上，报告归因排序的邻域稳定性以及零假设下归因分量的分布；缺少这两项报告的特征重要性排序，应当按未校准的噪声极值对待。

```python
# 精确 Shapley 值(小维度)与参考分布选择敏感性演示
import numpy as np
from itertools import combinations
from math import factorial

def shapley_exact(f, x, ref, n_feat=None):
    """精确 Shapley 值; ref 为参考(缺失)取值"""
    n = len(x) if n_feat is None else n_feat
    phi = np.zeros(n)
    for i in range(n):
        others = [j for j in range(n) if j != i]
        for r in range(len(others) + 1):
            w = factorial(r) * factorial(n - r - 1) / factorial(n)
            for S in combinations(others, r):
                zS = x.copy(); zS[[j for j in range(n) if j not in S]] = ref[[j for j in range(n) if j not in S]]
                zi = zS.copy(); zi[i] = x[i]
                phi[i] += w * (f(zi) - f(zS))
    return phi

# 一个带交互的玩具模型: f = 2*x0 + 3*x1*x2  (存在交互项)
f = lambda z: 2 * z[0] + 3 * z[1] * z[2]
x = np.array([1.0, 1.0, 1.0])
for name, ref in [("零参考", np.zeros(3)),
                  ("均值参考", np.array([0.5, 0.5, 0.5])),
                  ("随机参考", np.array([0.9, 0.1, 0.7]))]:
    print(f"{name}: phi = {np.round(shapley_exact(f, x, ref), 3)}")
# 交互项存在时, 不同参考分布给出不同的归因分配: 归因不是唯一确定的量
```
输出：
```text
零参考: phi = [2.  1.5 1.5]
均值参考: phi = [1.    1.125 1.125]
随机参考: phi = [0.2   2.295 0.495]
```

### 15.8.5 机制可解释性的现状与克制表述

机制可解释性目前有两条技术路线。第一条是自下而上的电路分析：在小模型上定位实现某个具体行为（如间接宾语识别）的最小计算子图，并用干预（消融某个注意力头后观察行为是否消失）验证。这类工作在玩具模型与小模型上可复现，但在前沿规模模型上难以穷尽——电路的数量随层数与头数增长，且特征之间存在叠加（superposition），即模型用少于特征数量的维度表示更多特征，这使得单个神经元不再对应单个概念。

第二条是稀疏自编码器（SAE）。SAE 在激活上训练一个带 $L_1$ 稀疏惩罚的自编码器：

$$\min_{W_e,W_d}\ \mathbb E\bigl[\|x-W_d\,\mathrm{ReLU}(W_e x)\|_2^2+\lambda\|\mathrm{ReLU}(W_e x)\|_1\bigr],$$

使激活被分解为若干稀疏方向的线性组合，得到的方向常被称为"特征"。SAE 学到的方向在很多案例中可被人类标注为可理解的概念，这使其成为当前最有用的工具之一。

但必须清楚三条限定。第一，SAE 学到的是对激活的一个重构基，重构保真度高不等于这些方向是模型实际使用的计算单元；二者的唯一可靠区分方式是干预实验（抑制该方向后模型行为是否按预测改变）。第二，字典大小的选择会导致特征分裂（feature splitting）：增大字典后，一个粗粒度特征会分裂为若干细粒度特征，说明"特征数量"不是一个客观量。第三，稀疏性与重构误差之间存在权衡，且存在大量"死亡"方向（几乎从不激活），报告的活跃特征数依赖于阈值设定。

对统计学者而言，这一方向的可贡献之处在于验证方法：把"某特征被模型使用"表述为一个可检验的命题，设计干预实验与零假设，用多次干预的效果分布而非单次演示来下结论，并报告效应量与样本量。当前文献中大量结论建立在单次案例展示上，这一状况本身就是一个统计问题。

叠加与稀疏字典的关系可以用一个最小实验直接呈现。在 $d=8$ 维的"激活"中植入 $m=16$ 个随机方向的"特征"（超完备，$m>d$，正是叠加的设定），每个样本只有 2 个特征活跃、幅度随机，观察到的激活是这些方向的线性组合。用带 $L_1$ 惩罚的字典学习（dictionary learning）求解：编码步用 ISTA（迭代软阈值算法）求稀疏系数，字典步用最小二乘更新，这是 SAE 的线性化版本。

```python
# 超完备稀疏字典的最小演示: 8 维空间中恢复 16 个叠加的特征方向
import numpy as np

rng = np.random.default_rng(9)
d, m, n_s = 8, 16, 8000          # 激活维数 / 真实特征数(> d, 叠加) / 样本数
K = 24                           # 字典大小(超完备)
W_true = rng.normal(0, 1, (d, m))
W_true /= np.linalg.norm(W_true, axis=0, keepdims=True)

A_act = np.zeros((m, n_s))
for j in range(n_s):
    idx = rng.choice(m, size=2, replace=False)
    A_act[idx, j] = rng.uniform(0.5, 2.0, size=2)
X = W_true @ A_act               # 观察到的激活: 维数 8 < 特征数 16

cols = rng.choice(n_s, K, replace=False)
D = X[:, cols].copy()            # 字典用随机数据列初始化
D /= np.linalg.norm(D, axis=0, keepdims=True)
lam = 0.05                       # L1 惩罚(稀疏度)
Z = np.zeros((K, n_s))
for it in range(150):
    lr = 1.0 / max(np.linalg.norm(D, 2) ** 2, 1e-9)   # ISTA 步长由谱范数决定
    for _ in range(30):
        G = Z - lr * (D.T @ (D @ Z - X))
        Z = np.sign(G) * np.maximum(np.abs(G) - lr * lam, 0)
    D = X @ Z.T @ np.linalg.pinv(Z @ Z.T)             # 最小二乘更新字典
    D /= np.linalg.norm(D, axis=0, keepdims=True)

err = np.linalg.norm(X - D @ Z) / np.linalg.norm(X)
match = np.abs(D.T @ W_true).max(axis=0)              # 每个真实方向的最佳匹配
print(f"相对重构误差 = {err:.3f}   (激活维数 {d}, 特征数 {m}, 字典大小 {K})")
print(f"真实方向最佳匹配余弦: 中位数={np.median(match):.3f}  最小={match.min():.3f}")
print(f"被高质量恢复(|cos|>0.9)的真实特征比例 = {(match > 0.9).mean():.2f}")

```
输出：
```text
相对重构误差 = 0.043   (激活维数 8, 特征数 16, 字典大小 24)
真实方向最佳匹配余弦: 中位数=0.999  最小=0.990
被高质量恢复(|cos|>0.9)的真实特征比例 = 1.00
```


16 个超过维数的特征方向全部以 $|\cos|>0.99$ 的精度被恢复，相对重构误差 0.043。结果与叠加假说的逻辑一致：叠加使单个神经元不再对应单个特征，但只要特征激活足够稀疏，超完备的线性字典仍能把它们逐个解开——这正是 SAE 在真实激活上被寄予希望的原因。同时需要看清这个演示的边界：这里特征的生成机制是线性且稀疏性是构造出来的，而前文列出的三条限定（重构保真不等于计算单元、特征分裂、死亡方向）在真实激活的非线性与相关性下都会使恢复质量下降。本演示支持的是"稀疏性原则上可以解开叠加"这一原理层面的命题，把它外推为"SAE 学到的方向就是模型实际使用的特征"，中间还隔着干预验证这一步。

## 15.9 因果AI

### 15.9.1 语言模型学到的是条件分布而非干预分布

语言模型的训练目标是序列的极大似然：

$$\max_\theta\ \sum_{t}\log p_\theta(x_t\mid x_{<t}),$$

即拟合观测文本的联合分布 $P(X)$。由此得到的任何条件概率 $P(Y\mid X)$ 都是从观测分布中读取的。因果推断关心的是干预分布 $P(Y\mid do(X))$，二者在后门可调整的情形下满足

$$P(Y\mid do(X=x))=\sum_{z}P(Y\mid X=x,Z=z)\,P(Z=z),$$

其中 $Z$ 为阻断所有后门路径的协变量集合。二者的差距即混杂偏倚。语言模型不会自动做这个调整，因为训练目标中没有任何机制要求它区分"与 $X$ 共同出现"和"由 $X$ 导致"。

这一区别在五个具体场景中表现出来。

| 场景 | 表现 | 机制 |
|---|---|---|
| 上下文混杂 | 提示中提到的变量与目标变量共同由第三因素决定，模型按共现作答 | 观测分布中的相关性被直接读取 |
| 反事实提问 | "如果当时没有 X 会怎样"要求的是 $P(Y\mid do(\neg X))$ 的反事实，模型按文本模式续写 | 训练语料中的反事实表述分布与真实反事实不同 |
| 选择偏倚 | 训练语料本身是选择的结果（发表偏倚、幸存者偏倚） | 语料的边际分布不等于总体分布 |
| 捷径学习 | 模型学到"答案风格—答案正确"的虚假相关 | 标注数据中的伪相关 |
| 方向混淆 | 文本中"A 因为 B"的语序被当作因果方向 | 报道惯例与因果方向不一致 |

### 15.9.2 因果工具能否在大模型场景中落地

Pearl 的 do-calculus 提供在给定因果图与观测数据时识别干预分布的规则体系。它在大模型场景中的困难不在于数学，而在于因果图的可用性：语言模型的"世界"是文本，变量与因果边没有先验定义，因此无法直接套用。

可落地的情形是那些变量明确、干预可执行的场景，而这些场景恰恰是应用侧而非模型内部：

| 方法 | 可落地场景 | 识别假设 | 主要风险 |
|---|---|---|---|
| 双重差分（DiD） | 评估"上线 AI 助手"对产出/效率的影响，有用户面板数据 | 平行趋势；无同期其他冲击 | 处理组与对照组的可比性；溢出效应 |
| 断点回归（RDD） | 按分数阈值触发人工复核、模型路由、风险分级 | 断点处连续性；无操纵 | 带宽选择；阈值处样本量不足 |
| 工具变量（IV） | 随机化"是否提供检索/工具"作为鼓励设计，估计使用的效应 | 相关性、排除限制、单调性 | 排除限制在 LLM 场景难以论证 |
| 随机实验 | 提示模板、模型版本、路由策略的 A/B 测试 | 随机化 | 干扰效应；多重比较 |
| DoWhy 等工具 | 显式建模假设并做反驳检验 | 依赖输入的因果图 | 图错误时输出仍然"运行成功" |

三种计量方法中，DiD 与 RDD 的可信度最高，因为它们的假设可以在数据中被部分检验（平行趋势的前期检验、断点处的协变量连续性检验）；IV 在 LLM 场景中最难，因为排除限制要求"工具只通过被研究的途径影响结果"，而模型对提示的任何改动都会引起连锁变化。

在模型内部做因果分析时使用的激活修补（activation patching），形式上是把某个中间激活替换为"反事实输入"下的激活并观察输出变化，这与干预的概念一致。但它不满足标准 IV 的排除限制：被修补的位置可能同时影响多条通路，且修补本身把模型推离了训练分布。因此其内部效度需要靠多个位置的对照修补与剂量—反应关系来支撑，而不是靠单次修补的成功。

### 15.9.3 语言模型作为混杂控制工具

一个正在普及的做法是用 LLM 从非结构化文本中提取协变量（从临床记录中提取吸烟史、从裁判文书中提取案由、从财报中提取行业），再把提取出的协变量用于下游的倾向得分匹配或回归调整。这一做法的价值是明显的：它把原本需要昂贵人工标注的协变量提取成本降低了若干数量级，使大样本因果研究成为可能。

风险同样明确，且可以精确刻画。提取是一个分类/测量过程，其误差不是经典测量误差，而是与目标变量相关的误分类。设真实协变量为 $Z$，提取值为 $\hat Z$，则：

| 误差类型 | 表现 | 后果 |
|---|---|---|
| 随机误分类 | 灵敏度与特异度均 <1，且与结局无关 | 残余混杂；回归系数向零衰减（回归稀释） |
| 差分误分类 | 提取误差在处理组与对照组间不同 | 偏倚方向不确定，可能反向 |
| 泄漏污染 | 提取时模型看到了结局信息 | 协变量本身成为结局的函数，调整后引入碰撞偏倚 |
| 系统性缺失 | 文本未提及即被判为"无" | 缺失被编码为负值，产生系统性偏倚 |

标准做法应当是：在一个人工标注的子集上估计灵敏度与特异度（并报告其置信区间）、把这两个参数代入测量误差校正（回归校正、SIMEX、或贝叶斯测量误差模型）、并做敏感性分析展示结论在误差参数的什么范围内改变。若只做提取而不做校正，得到的调整后估计仍然是偏的，且偏倚大小未知。

一个具体的操作建议：把标注子集作为金标准，分层抽样（按处理、按结局、按文本长度）以保证各单元的覆盖，样本量按估计灵敏度 ±0.05 的目标计算，并报告抽样设计（第 16.3 节给出率估计的样本量公式，第 16.10 节给出多重比较的处理）。

```python
# LLM 提取协变量: 误分类导致的残余混杂与回归校正 (regression calibration)
import numpy as np
rng = np.random.default_rng(5)

n = 20000
Z = (rng.random(n) < 0.5).astype(float)                        # 真实二值混杂
X = (rng.random(n) < 0.3 + 0.4 * Z).astype(float)              # 处理受 Z 影响
Y = 1.0 * X + 1.5 * Z + rng.normal(0, 1, n)                    # 真实处理效应 = 1.0

sens, spec = 0.80, 0.85                                        # 提取器的灵敏度/特异度
Zhat = np.where(Z == 1,
                rng.random(n) < sens,
                rng.random(n) < (1 - spec)).astype(float)      # LLM 提取值

def effect_adj(Zadj=None):
    cols = [np.ones(n), X] + ([Zadj] if Zadj is not None else [])
    return np.linalg.lstsq(np.column_stack(cols), Y, rcond=None)[0][1]

# 回归校正: 用已知的灵敏/特异度求 E[Z | Zhat], 用该条件期望做调整
q = Z.mean()
p_pos = q * sens + (1 - q) * (1 - spec)
E_Z_given_1 = q * sens / p_pos
E_Z_given_0 = q * (1 - sens) / (1 - p_pos)
Zcal = np.where(Zhat == 1, E_Z_given_1, E_Z_given_0)

print(f"不调整              : {effect_adj():.3f}   (混杂偏倚)")
print(f"用真实 Z 调整       : {effect_adj(Z):.3f}")
print(f"用 LLM 提取值调整   : {effect_adj(Zhat):.3f}   (残余混杂)")
print(f"用 E[Z|Zhat] 调整   : {effect_adj(Zcal):.3f}   (校正后)")
# 注意: 校正依赖灵敏度/特异度已知; 它们本身是估计量, 需报告置信区间并做敏感性分析
```
输出：
```text
不调整              : 1.603   (混杂偏倚)
用真实 Z 调整       : 0.985
用 LLM 提取值调整   : 1.377   (残余混杂)
用 E[Z|Zhat] 调整   : 1.377   (校正后)
```



## 15.10 评估基准与能力指数

### 15.10.1 基准污染

基准污染（data contamination）指测试集内容进入了模型的训练数据。它的形式不止一种：

| 污染类型 | 机制 | 检测手段 | 检测局限 |
|---|---|---|---|
| 直接重叠 | 测试题原文出现在训练语料中 | n-gram 重叠率、哈希匹配 | 改写与翻译可绕过 |
| 间接泄漏 | 网络上的题解、讨论帖被抓取 | 发布时间比对、来源追溯 | 难以穷举来源 |
| 指令微调泄漏 | 对齐阶段使用了含测试集的数据 | 提示敏感度测试 | 无法从外部观测 |
| 迭代自我污染 | 后续模型训练语料中含前代模型的输出 | canary 字符串 | 仅在自建基准上可行 |
| 基准驱动的过拟合 | 反复按同一基准调参 | 保留集（held-out）复测 | 需要未公开题目 |

Sainz 等人（*NLP Evaluation in trouble: On the Need to Measure LLM Data Contamination for Each Benchmark*，arXiv:2310.18018）指出，污染程度必须在每个基准上单独测量，而不能对整个训练集做一次性的笼统判断。检测手段的共同局限是：它们只能发现字面重叠，无法发现语义等价的改写与翻译，因此"未检测到污染"不等于"无污染"。

### 15.10.2 选择性报告与多重比较

选择性报告的形式包括：在多个 checkpoint 中只报告最好的、在多个提示模板中只报告最好的、在多个子集中只报告最好的、在多个指标中只报告显著的。当候选配置数为 $m$ 时，最好值的期望高于任一配置的期望，且偏差随 $m$ 与方差增大。这是极值统计的直接后果，与第 15.3.6 节的 winner's curse 是同一现象。

标准做法在第 16.10 节给出：预先注册主指标与主要比较、对次要比较做多重比较校正、报告全部配置的结果分布而非最优值。

### 15.10.3 单一分数掩盖的能力异质性

一个基准的总分是题目上的平均。平均值掩盖的信息至少包括：难度的分层表现、题型的分层表现、语言的覆盖、以及方差。两个总分相同的模型可能有完全不同的能力剖面：一个在各子项上均匀，另一个在简单题上接近满分而在难题上接近零分。对部署而言这两个模型不等价。

能力指数（如 Epoch AI Capabilities Index）尝试把多个基准聚合成单一时间序列，用于刻画能力前沿的推进速度。据 Epoch AI 公布的对比，自 2024 年 9 月推理模型问世以来，推理模型对应的能力指数以每年约 14 点的速度增长，非推理模型约为 6 点/年。聚合指数的构造涉及基准选取、权重设定与缺失值处理，这些选择会影响结论，引用时应当连同方法论一并引用（https://epoch.ai/eci）。

### 15.10.4 样本量不足导致的分数抖动

基准分数是有限题目上的比率估计。若题目数为 $n$、真实正确率为 $p$，则估计的标准误为 $\sqrt{p(1-p)/n}$。当 $p\approx0.5$、$n=500$ 时，标准误约为 $0.022$，即 95% 置信区间宽度约 $\pm4.4$ 个百分点。这一宽度足以覆盖多个模型之间的常见差距，意味着大量公布的排名差异落在噪声范围内。

三个可操作的改进：增大 $n$（或使用分层题目集合）、使用配对比较（同一题目上比较两模型，消除题目难度方差，见第 16.5 节）、以及报告置信区间而非点估计。

```python
# 基准分数的抖动: 边际区间 vs 配对差值的区间
import numpy as np
from scipy.stats import norm
rng = np.random.default_rng(6)

n_items = 500                 # 题目数
pA, pB = 0.62, 0.65           # 两模型真实正确率
rho = 0.8                     # 题目难度导致的两模型结果相关

# 共享的 latent 因子 z 表示题目难度; 相关越高, 配对设计收益越大
z = rng.normal(0, 1, n_items)
def draw(p):
    u = np.sqrt(rho) * z + np.sqrt(1 - rho) * rng.normal(0, 1, n_items)
    return (u > norm.ppf(1 - p)).astype(int)

cA, cB = draw(pA), draw(pB)
accA, accB = cA.mean(), cB.mean()
se_pair = (cB - cA).std(ddof=1) / np.sqrt(n_items)   # 配对差值的标准误

print(f"A={accA:.3f} ± {1.96*np.sqrt(accA*(1-accA)/n_items):.3f}"
      f"   B={accB:.3f} ± {1.96*np.sqrt(accB*(1-accB)/n_items):.3f}")
print(f"配对差值 = {(cB-cA).mean():+.3f} ± {1.96*se_pair:.3f}")
print("配对设计消除题目难度方差, 区间显著更窄")
```
输出：
```text
A=0.616 ± 0.043   B=0.652 ± 0.042
配对差值 = +0.036 ± 0.033
配对设计消除题目难度方差, 区间显著更窄
```



### 15.10.5 涌现能力是否为度量假象

"涌现能力"指在模型规模达到某一阈值后，某些任务的表现从接近随机突变为显著高于随机。Schaeffer 等人（*Are Emergent Abilities of Large Language Models a Mirage?*，arXiv:2304.15004）给出的解释是：这类突变主要来自指标的选择。当使用不连续或非线性指标（如精确匹配率、多步任务的连乘成功率）时，逐 token 错误率的平滑下降在指标上表现为阶跃；换成连续指标（如 token 级准确率、对数似然）后，同一批数据的曲线变为平滑。

对统计学者而言，这一争论的要点是可测量的：给定一个平滑下降的每步正确率 $p(N)$，复合指标 $p(N)^{L}$ 随 $N$ 的表现形态由 $L$ 与 $p$ 的尺度共同决定。这类"指标变换制造出的相变"在统计中并不罕见，检查办法是把指标换成连续版本并重绘曲线。作为背景，Wei 等人（*Emergent Abilities of Large Language Models*，arXiv:2206.07682）是最初提出"涌现能力"表述并汇总相关现象的论文，Schaeffer 等人的度量批评针对的正是这类现象的报告方式；两篇论文连读比单读任何一篇更接近实情。

## 本章小结

- 公开人类文本的存量估算量级在 $4\times10^{14}$ tokens，耗尽时间的估计依赖去重率、质量阈值、多模态是否计入等假设，引用时应连同假设给出。
- 递归训练造成的分布退化由近似误差、估计误差与尾部截断三类误差累积；一维高斯情形下尺度参数按 $\exp(-t/n)$ 收缩，混入真实数据可显著减缓。
- Scaling Laws 是对数坐标上的回归外推：Kaplan 形式的三个指数在 $0.05$–$0.10$ 量级，Chinchilla 联合形式给出 $A\approx406.4$、$B\approx410.7$、$E\approx1.69$、$\alpha\approx0.34$、$\beta\approx0.28$，外推预测区间随距离线性变宽；联合形式的两个指数只在 $(N,D)$ 网格设计下可识别，仅用前沿附近的运行点拟合时标准误大出约两个数量级且高度相关。
- 多数投票降低方差而不改变偏差，在单次正确率低于 $1/2$ 时会降低正确率；采样之间的相关性使有效样本量远小于采样条数。验证器进入后，加权软投票在信噪比适中时优于多数投票与硬筛选，而 best-of-$n$ 的收益必须区分"候选含正确解的概率"与"验证器选中它的概率"，被选候选的表观验证分含赢者诅咒式的选择偏倚。
- Agent 的成功率随步骤数呈 $p^L$ 的乘法结构，pass@$k$ 与 pass$^k$ 回答不同问题，跨 $k$ 不可比。
- 量化、蒸馏等压缩技术会改变输出分布与校准，压缩后必须重新评估校准而非沿用原模型结论。
- 事后解释与机制可解释性处理不同问题；Shapley 归因的参考分布选择不唯一，归因不等于因果效应。局部线性解释对随机函数同样给出高拟合优度与看似清晰的特征排序，但其排序在输入邻域内不稳定，且与随机标签零假设下的噪声极值难以区分，解释报告应附稳定性与零假设两项检查。机制分析一侧，稀疏字典在线性合成数据中能把超过维数的叠加特征方向逐个恢复，这支持的是稀疏性解开叠加的原理，不是"SAE 方向即模型特征"的结论。
- 语言模型的训练目标是拟合观测分布 $P(Y\mid X)$，不产生干预分布 $P(Y\mid do(X))$；用 LLM 提取协变量时必须估计灵敏度与特异度并做测量误差校正。
- 基准污染、选择性报告、单一分数与样本量不足共同解释了分数排名的大部分抖动；配对比较与置信区间报告是低成本的改进。
- 发表渠道中 AISTATS 与统计学期刊对统计学贡献最友好，COLT 与 *Annals of Statistics* 对理论深度要求最高。
